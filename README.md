# Lira — Магазин мусульманской одежды

## Описание
Lira — это интернет-магазин мусульманской одежды и аксессуаров, созданный как современный и удобный веб-сайт для продаж женской одежды, аксессуаров, косметики и исламской атрибутики. Проект разработан в стиле современного интернет-магазина с адаптивным интерфейсом и функциональной корзиной.

## Технологии
- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- LocalStorage
- Git / GitHub

## Основные функции
- Корзина покупок с подсчетом количества и общей суммы
- Сохранение корзины в localStorage
- Форма регистрации с проверкой совпадения паролей
- Поиск по вопросам и ответам в разделе FAQ
- Адаптивный дизайн для разных устройств
- Красивые карточки товаров и модальное окно корзины

## Структура проекта
- `index.html` — главная страница магазина
- `about.html` — раздел "О нас"
- `register.html` — страница регистрации
- `FAQ.html` — ответы на вопросы
- `style.css` — стили проекта
- `script.js` — логика магазина, корзины и валидации
